---

Цель работы

Создание консольного приложения «Интернет-магазин» для управления каталогом товаров и корзиной покупателя с использованием ключевых принципов ООП, безопасного ввода данных и контроля версий через Git.

---

Структура проекта

· Product.h / product.cpp — класс сущности «Товар» (артикул, название, цена, количество на складе).
· Cart.h / cart.cpp — класс «Корзина» (хранение указателей на выбранные товары, подсчёт итоговой суммы и количества).
· input.h — вспомогательные функции безопасного ввода (readInt, readDouble, readString).
· main.cpp — меню пользователя, обработчики команд и точка входа в приложение.

---

Основной функционал

1. Добавление товара: ввод нового товара в каталог через текстовое меню (артикул, название, цена, количество).
2. Изменение товара: редактирование характеристик существующего товара по его номеру в каталоге.
3. Просмотр каталога: вывод полного списка товаров с указанием цены, артикула и наличия на складе.
4. Работа с корзиной: добавление товаров из каталога в корзину и просмотр её содержимого.
5. Оформление заказа: заказ выбранного количества товара с проверкой достаточности на складе и уменьшением остатка после покупки.
6. Защита от ошибок ввода: устойчивость к вводу некорректных символов (букв, пробелов и спецсимволов) через функции readInt, readDouble, readString.

---

Использованные средства C++

· Умные указатели std::unique_ptr для владения товарами каталога и заказами.
· Сырые указатели Product* в корзине — без владения, только наблюдение за товарами каталога.
· Динамические массивы std::vector для хранения каталога, корзины и заказов.
· Кодировка UTF-8 и настройка консоли Windows через SetConsoleOutputCP / SetConsoleCP.
